# Heirloom Mixology

Mixology adds fruit trees, fresh juice and cocktails to Heirloom. Grow the ingredients, prepare them at your bar, and use `/hl` to look up the recipes available on your server.

## Start here

- **[Fruit trees and harvesting](mixology-fruit-harvesting.md):** planting, starter packets and ripening fruit.
- **[Juicer](mixology-juicer.md):** blend three produce items into two bottles, including mixed juices.
- **[Mixology Table](mixology-shaker.md):** build the counter, add ingredients and shake a round of three drinks.
- **[Espresso Martini, from the beginning](mixology-espresso-martini.md):** roast coffee, brew espresso, make Coffee Liqueur and use it in the finished cocktail.

## Which addons do I need?

| Setup | What it adds |
| --- | --- |
| Heirloom Core + Mixology | Fruit trees, pineapple, the Juicer, cocktails, mocktails, fruit dishes and standalone spirit recipes |
| Add Café | Coffee Liqueur, Espresso Martini, Black Russian, White Russian, Mudslide and B-52 |
| Add compatible Distillery | Brewed spirits and wine used by integrated recipes; actual ingredient strength carries through to cocktails, and alcoholic drinks use Distillery's drunkenness system |

Café and Distillery are optional. The Espresso Martini example needs Café; it works with or without Distillery. When Distillery is active, its real brewed spirits replace Mixology's standalone spirit recipes. The in-game browser follows the installed addons and server configuration.

Use Mixology with a compatible Core build containing the Mixology Table and Juicer. Install the addon beside Core in `plugins/`, with the server stopped. No resource pack or client mod is required. See [Heirloom installation](../getting-started/installation.md) for the base plugin setup.

## More from the harvest

Fruit is useful outside the bar. Mixology includes Orange Chicken, Yellow Coconut Curry and Guacamole, and suitable fruit can also be used in Core's jams and ice creams. Guacamole is an optional taco ingredient. Check `/hl` for the exact ingredients on your server.

Server owners can edit items, recipes and acquisition settings. Mixology's starter packets, world drops and chest loot are configurable rather than compulsory.
