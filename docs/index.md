# Heirloom Wiki

<figure class="hl-figure">
  <img src="images/heirloom-wide-banner.png" alt="Heirloom là plugin chuyên phục vụ việc nấu ăn và làm vườn dành cho máy chủ Paper.">

</figure>

Heirloom bổ sung hệ thống nấu ăn, cây trồng tùy chỉnh, chất lượng thực phẩm, chế độ ăn, hệ thống dinh dưỡng, khám phá công thức mới và vô cùng nhiều nội dung mà không cần phải cài gói tài nguyên. Quản trị viên có thể tùy chọn tích hợp Nexo hoặc ItemsAdder để thay thế hình ảnh mặc định bằng hình ảnh tùy chỉnh từ gói tài nguyên.
