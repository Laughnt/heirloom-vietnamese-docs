# Heirloom Wiki

<figure><img src="../.gitbook/assets/heirloom-wide-banner.png" alt="Heirloom is a physical cooking and gardening plugin for Paper servers."><figcaption><p>Heirloom is a physical cooking and gardening plugin for Paper servers.</p></figcaption></figure>

Heirloom adds in-world cooking stations, custom crops, food quality, dietary labels, recipe discovery, and addon content without requiring a resource pack. Optional Nexo and ItemsAdder integrations can replace the player-head fallback visuals when a server wants a resource-pack presentation.

## Start Here

* New players: [First Meal](getting-started/first-meal.md), [First Farm](getting-started/first-farm.md), then [Recipe Browser](getting-started/recipe-browser.md).

## What The Wiki Covers

### Players

Cooking, farming, recipe search, favourite food, advancements, mastery, and feasts.

### Server Owners

Install, configure, protect claims, localize, debug, and update safely.

### Creators

Write JSON content, tune food systems, and map visual items for Nexo or ItemsAdder.

### Addons

Distillery and Cafe have full pages. Future addons are tracked separately.
