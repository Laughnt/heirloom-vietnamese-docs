# Lệnh

Heirloom Core sử dụng `/hl` hoặc `/heirloom`. Distillery sử dụng `/hld`. Cafe sử dụng `/hlc`.

Danh sách đầy đủ các lệnh được trình bày trong [Tham chiếu Lệnh](../reference/commands.md).

## Các lệnh quản trị cần biết

```text
/hl reload
/hl cheat
/hl give <item> [amount]
/hl debug test
/hld devmode status
/hlc list
```
